# References, citations, bibliography

`python3 lmr2svg.py examples/references/deck.lmr -o references.html`

- attach `^name` to a slide/heading/table/…, point back with `@name` (shows its number/title)
- a bibliography entry is a line `^key: text`; cite it with `@key` → a numbered `[n]`
- `<https://…>` becomes a link
